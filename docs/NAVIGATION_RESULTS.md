# 高度タスク：既知地図での地点巡回（2026-10-24）

> この記録は固定地図での初回実装の結果です。後続の通路封鎖・再計画については [REPLANNING_RESULTS.md](REPLANNING_RESULTS.md) を参照してください。

作業開始前のチェックポイントは `0f73528` です。
Go2に障害物を迂回させ、自然言語で指定した順に目的地を訪れるタスクを追加しました。

Codexが出力するのは名前付き地点のリストです。固定地図上で経路全体を検査してから、
0.2秒ごとの実測位置に応じて前進速度・旋回速度を調整します。
関節制御と物理は引き続き公開済みMoE方策とMuJoCoが担当します。
観測はシミュレータから得る座標です。画像から地点や障害物を認識した結果ではありません。

## 実行結果

Python 3.12.12、MuJoCo 3.3.7、ONNX Runtime 1.23.2、WSL2 Ubuntu 24.04、
Windows Codex CLI 0.157.0で、次の2種類の日本語指示を実行しました。

| 指示 | 実際のCodex経路 | 実行時間（最終停止を含む） | 停止後の最終誤差 |
| --- | --- | --- | --- |
| 北側を回って青→緑 | north_gate → blue → green | 30.8秒 | 8.9 cm |
| 南側を回って緑→青→出発地点へ帰還 | south_gate → green → blue → north_gate → home | 47.6秒 | 6.8 cm |

両方とも指定順に到達して終了しました。実行中は全物理ステップで接触と接近を監視し、
障害物による中断はありませんでした。10 Hzログでの最小障害物クリアランスはそれぞれ
約0.211 mと約0.191 m、直立度の最小値は0.9985と0.9960でした。
クリアランスは箱とロボット中心の距離から、仮定したロボット半径0.45 mを引いた値です。
実際の各リンクとの最短距離そのものではありません。

最初の経路は `outputs/navigation-codex.mp4` に31.8秒・720×480・25 fpsで録画しています。
録画には開始前の姿勢安定化1秒も含みます。複数時刻のフレームを抽出し、箱の迂回、
青への到達、緑への移動を目視確認しました。逆順と帰還のケースは状態ログで確認し、録画はしていません。
数値の抜粋は [navigation-validation.json](navigation-validation.json)、
詳細ログはローカルの `outputs/plan-*.json` にあります。

```bash
bash scripts/demo.sh --task navigation --planner codex --headless --prompt '赤い障害物の南側を回って緑の地点へ行き、次に青の地点を訪れ、最後に黄色の出発地点へ戻って'
```

## 制約とテスト

名前付き地点は最大8個です。経路はロボット半径0.45 mと余裕0.10 mを加えた障害物と
線分が交差しないことを検査します。不正な経路は拒否し、サンプル計画への置き換えはしません。
追従では前進0.25 m/s、旋回0.6 rad/s以下の指令を使います。
最大移動時間90秒、各地点35秒で打ち切り、最終停止後の誤差0.12 m以下を完了条件にしています。
開始時の姿勢安定化1秒と最終停止2秒は移動時間の上限とは別です。

最初の到達判定だけでは停止中の微小な移動で許容誤差を超える場合があったため、
追従時は8 cm以内まで近づき、停止後に12 cm以内か再検査する構成にしました。

WSLで20テストが成功しました。既存の歩行テストに加え、経路の交差検査、不正JSON、
LLM経路の検証、動かない場合の時間制限、実物理での迂回・到達・停止を検査しています。
意図的に箱へ直接進む物理テストも追加し、接触前の中断とトルクゼロを確認しました。

```bash
PAI_SIM_TEST=1 .venv-wsl/bin/python -m unittest discover -s tests -v
```

## 未対応の範囲

地図と地点の名前・位置は固定です。Codexは計画時に一度だけ呼び、位置の追従はPythonで行います。
動的な障害物、カメラ認識、自己位置推定、LLMによる実行中の再計画には対応していません。
安全停止はオフラインシミュレーションの中断であり、実機の緊急制動を検証したものではありません。
今回の2経路の成功だけで、任意の自然言語や環境に一般化できるとは判断していません。
学習の比較実験や課題の独自性の評価は今後の作業です。

接触の判定にはMuJoCoの接触情報を使用しています。
仕様は [MuJoCo 3.3.7 mjContact](https://mujoco.readthedocs.io/en/3.3.7/APIreference/APItypes.html#mjcontact) を参照してください。
